# Reasoning Scaffold

LazyDev is an orchestration layer, not a claim that every underlying model has the same capability. The scaffold improves reliability by making execution explicit and evidence-driven.

Use: understand → inspect → plan → act → observe → verify → stop.

For non-trivial tasks, keep an internal micro-plan, ground decisions in repository/tool evidence, preserve scope, and repair observed failures. Never invent APIs, files, test results, or UI details.

For UI, compile a design system before implementation and verify responsive/state/accessibility behavior after implementation.
