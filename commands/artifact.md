description: Create a standalone deliverable in LazyDev's canonical artifact directory.

Create the requested standalone deliverable under `LAZYDEV_ARTIFACT_DIR`. On Termux this is `/storage/emulated/0/lazydevfile`; on Windows/Linux/macOS it is the user's `lazydevfile` directory. Choose a descriptive filename; do not default to `index.*` unless explicitly required. Verify the final file exists there before reporting the path. $ARGUMENTS
