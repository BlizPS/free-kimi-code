# Contributing

Keep changes focused.

Read the relevant code before editing, follow the existing style, avoid unnecessary dependencies and rewrites, and verify behavior before opening a pull request.

For skill changes, keep `SKILL.md` concise and actionable. Do not claim a check was run unless it was actually run. Run `python3 scripts/safety_scan.py`, `python3 scripts/eval_skills.py`, `python3 scripts/compat_smoke.py`, and `python3 scripts/validate.py` before submitting.
