`RESEARCH → TARGET → RISK → PROOF → RUN → INTERPRET → STOP/EXPAND`

Search when current facts matter. Map changed contracts; rank risk by fan-out/impact. Run proof: **static → focused → integration → build/package/runtime → broader**.

Expand after failure, fan-out, untested risk, requirement, or security need. Interpret coverage: `lint ≠ runtime`; `build ≠ behavior`; `focused ≠ whole-system`; `skipped ≠ passed`.
